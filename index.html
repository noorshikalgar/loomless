Turn a working session into a readable story.

Loomless watches you click through a feature, debug an issue, or run a demo — and turns it into an ordered, skimmable write-up with screenshots and captions. Not a video. Built for humans and AI coding agents.

Get started View on GitHub

Free, open source (MIT), local-first — no accounts, nothing leaves your machine unless you turn on optional LLM caption polish.

Everything a debugging session needs, captured automatically

Each feature below is real and shipped — not a roadmap promise.

Automatic click capture

On macOS, record start watches your clicks with a listen-only event tap and captures a window-scoped screenshot per click — with an optional highlight ring around what you clicked.

Terminal capture

loomless run -- <cmd> captures a command plus its live output as a step — the same way on Linux and macOS, no shell hook required.

Redact & annotate

Five shape tools (rectangle, circle, line, arrow, freehand) plus solid/blur redaction, numbered highlight callouts, cropping, and full undo/redo/reset history.

Secret masking

Notes, window titles, and command output are pattern-matched for API keys, tokens, and password=-style assignments, masked before anything touches disk.

Markdown / PDF / Slides

Export the same session three ways — a Markdown file for a PR, a PDF, or a self-contained HTML slide deck — rendered directly from session data, no headless browser involved.

Local web editor

Reorder, hide, or caption steps, edit screenshots, live-preview Markdown, and export — all from one page, with four built-in color themes (Tokyo Night, Gruvbox, GitHub Dark, and the default).

Terminal dashboard (TUI)

Browse every session, search, and jump into edit/export — all without leaving the terminal.

Agent-driven capture (MCP)

loomless mcp runs an MCP server so an AI coding agent — Claude Code, for instance — can narrate its own work into the exact same story format a human would produce.

Auto-captions

A local template grounded in the real UI element you clicked (macOS Accessibility API), with optional LLM rewrite via Anthropic, OpenAI, Gemini, or a local Ollama server — off by default.

How it works

Four commands, start to finish.

1

Start recording

loomless record start <name> begins watching — clicks are captured automatically on macOS.

2

Work normally

Click around, or add context explicitly with loomless step / loomless run.

3

Edit

loomless edit <name> opens the local web editor — reorder, redact, annotate, caption.

4

Export

loomless export <name> — Markdown, PDF, or Slides, right from the editor or the CLI.

Try it

The whole core loop, copy-pasteable.

# build
go build -o loomless ./cmd/loomless

# record
./loomless record start my-first-story        # add --highlight for a click ring
./loomless step "optional note, no click needed"
./loomless run -- go test ./...               # captures the command + output
./loomless record stop

# edit, then export
./loomless edit my-first-story                # reorder / redact / annotate / caption
./loomless export my-first-story              # Markdown (default)
./loomless export my-first-story --format pdf
./loomless export my-first-story --format slides

Platform support

Know what to expect before you hit a surprise.

PlatformStatus
macOSFully supported — the primary development platform, every feature is built and exercised here.
Linux (X11)Window/terminal capture and export verified against a real X11 session. Automatic click-capture isn't implemented; Wayland isn't supported.
WindowsNot supported yet — doesn't currently build. Not on the near-term roadmap.
